# Grace Smith — TESOL Teaching Portfolio

A responsive, accessible multi-page portfolio prepared for GitHub Pages. The site includes a home page and separate pages for About Me, Teaching Philosophy, Experience, Teaching Materials, Evaluations, and Contact.

## Publish with GitHub Pages

1. Keep the contents of this folder at the repository root. The site uses `index.html`, the section pages, `styles.css`, `.nojekyll`, and the `assets` folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. GitHub will show the published site address in the Pages settings. Updates to the publishing branch will trigger a new deployment.

## Update the portfolio

- Edit the relevant page: `about.html`, `teaching-philosophy.html`, `experience.html`, `teaching-materials.html`, `evaluations.html`, or `contact.html`.
- Update the top navigation links on each page if you add, remove, or rename a page.
- Keep the PDF files in `assets/documents/` and update their links in `teaching-materials.html` if filenames change.

## Accessibility and privacy notes

- The site uses semantic page headings, a skip link, keyboard-visible focus, readable line lengths, responsive layouts, and reduced-motion support.
- The lesson-plan download replaces a student first name with “A student.” The résumé's personal Gmail address and phone number are omitted from the public website; the Contact page uses the BYU address provided for the portfolio.
- Additional lesson plans, teaching demonstrations, assessment evidence, research/evaluation evidence, and course documents are marked as forthcoming for this initial version.
- Review the public site and downloadable files before sharing them widely. GitHub Pages content is public.
