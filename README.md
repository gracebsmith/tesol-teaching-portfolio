# Grace E. B. Smith — TESOL Teaching Portfolio

A responsive, accessible, single-page portfolio prepared for GitHub Pages. The site's content is organized into Home, About Me, Teaching Philosophy, Experience, Teaching Materials, Evaluations, and Contact.

## Publish with GitHub Pages

1. Create a **public** repository under your personal GitHub account. A descriptive name such as `tesol-teaching-portfolio` works well.
2. Upload the contents of this folder to the repository's root. Keep `index.html`, `styles.css`, `.nojekyll`, and the `assets` folder together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. GitHub will show the published site address in the Pages settings.

## Update the portfolio

- Edit `index.html` to revise writing, add evidence, or change the navigation labels and section links.
- Keep the PDF files in `assets/documents/` and update their links in `index.html` if filenames change.
- After uploading or committing updates to the publishing branch, GitHub Pages rebuilds the site.

## Accessibility and privacy notes

- The site uses semantic sections, a skip link, keyboard-visible focus, readable line lengths, responsive layouts, and reduced-motion support.
- The lesson-plan download replaces a student first name with “A student.” The résumé's personal Gmail address and phone number are omitted from this public version; the Contact section uses the BYU address provided for the portfolio.
- The portfolio requirements call for additional lesson plans and teaching demonstrations, as well as assessment and research/evaluation evidence. Those areas are marked as forthcoming for this initial version.
- Review the public site and downloadable files before sharing them widely. GitHub Pages content is public.
